# ARC-SV2 code review — 2026-09-29

Scope: `new-src/arcsv2` (Python engine, Rust core, ML modules). pytest 22/22, ruff, cargo test 8/8, clippy all pass. End-to-end check used a haplotype-aware pair simulator (60 kb, 30x, 1 kb SV at 30,000), `call_evidence` with no breakpoints supplied.

## End-to-end result (as shipped)
- DEL HOM -> `ABC -> AACC`; DEL HET -> `ABC -> AABCC`; DUP -> `AABBCC`; INV -> `AABBC`; DEL+INV -> nothing. All wrong.
- After a local one-line fix to blocker 1: DEL HOM/HET correct; DUP correct path but HET called HOM; INV and DEL+INV still produce no calls.

## Blockers
1. Spurious tandem-dup edges (`engine/caller.py` build_graph, same_block_dup branch): any concordant pair in the 5% insert tails becomes a B.out-B.in edge (209 and 174 reads per block in sim). Needs outward orientation (reverse read upstream of forward read).
2. Inversions cannot be called.
   a. DRP types swapped vs `orig:pecluster.py:66-70` (both-reverse = InvR at reference_start; both-forward = InvL at reference_end). Breakpoints land ~1 insert off; 4 breakpoints instead of 2.
   b. `_implied_insert` handles FR only; FF/RR pairs get the genomic span, fail the 95% window, so no inversion edges are ever added.
3. Likelihood credits a read only when its adjacency is a direct path step (`likelihood.py` score_path). The original sums f(offset + block distance) over all placements (`orig:sv_inference.compute_edge_likelihood`, `helper.get_block_distances_between_nodes`). Pairs spanning a small block look like deletion evidence. Also: n in G^n is the informative-read count, not all reads in the locus; read_index is the whole chromosome.
4. Evidence not wired: soft-clip and split-read code is never called from the SAM path (sr_support always 0); mate-unmapped pairs are dropped before pairing, so no hanging reads and no insertion blocks (`_` calls impossible); TLEN read from tags instead of column 9.
5. ML filter not implemented: ml-train writes presets and thresholds only; xgboost/sklearn never imported; ml-predict probability = logistic(score_vs_ref / 50); PCA never fit.

## Major
6. KDE window not capped at 3x median (orig caps, `bamparser_streaming.py:87`); insert list includes deletion-spanning FR pairs.
7. Scale: whole SAM in memory; cluster_drps is O(n^2) (1k DRPs 0.14 s, 4k 2.4 s; x5 passes per type); every locus scores every read in the chromosome graph; Graph.neighbors scans all edges. Rust kernels are not called.
8. merge-filter BEDs read without chromosome, so every call is filtered against all chromosomes' intervals; same sample can be counted twice in a merged call.
9. HET DUP called HOM in simulation (check against original).

## Minor
- PARITY.md item 2 is wrong: orig normpdf is a log density, so normpdf(0) - normpdf(3) = 4.5, same as paper mode.
- bp_uncertainty, sv_bp_uncertainty always 0; filter always PASS; inslen NA (ML features constant).
- VCF BND brackets fixed regardless of junction orientation.
- Null replicates share one RNG stream (comment says independent); --threads, --jobs ignored; --region only uses chrom.

## Test gaps
- test_deletion_is_called supplies breakpoints and uses a tail-free insert list, which hides blocker 1.
- scripts/simulate.py only creates read evidence for DEL; other templates sample from the reference. test_sim only checks the checksum.

## Suggested order
Fix 1-2 with per-template e2e tests, then 3, then 4, then scale (7), then real ML training (5).
