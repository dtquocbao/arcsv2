## Fixed since round 10

- **Single-read clip refinement:** `_stamp_clip_positions_from_softclips` uses any soft clip inside an already-open interval. `load_region` now returns the clips, and `call_sam` passes them through.
- **`bp_point_source` column** marks each junction as `clip` or `mid`.
- **Tolerant labeling:**
  - Only runs when the first attempt is not 1.
  - Only for `mid` junctions, at most 3 of them.
  - Tries both edges, the midpoint and a 10 bp grid.
  - Records `label_bp_shift`.
- **Minimum block size:** `merge_intervals_for_min_block` joins breakpoints whose block in between would be shorter than `min_affected_length` (50 bp).
- **`check_label_pilot.py`** reports every mismatch, and `pilot_large.py` runs the check itself.

## Findings

### 1. Small complex events still get an extra block (medium, caller)

- The one label-0 call in the large pilot is a **wrong call, correctly labeled 0**:
  - **Truth:** `inv.del` HOM, 300 bp, at 1951200-1951500.
  - **Called:** `ABCDE -> AD'E`, where B = 1951118-1951200 (82 bp) is an extra deleted block.
- 82 bp is above the new 50 bp minimum, so the merge does not remove it. The same event type is also the one remaining error in the 30x demo (`inv.del` HOM 300 bp, "wrong type").
- The extra boundary at 1951118 has no clip support; the true boundaries do. It is most likely a discordant-pair CI edge.

**Suggested fix:**
- When a breakpoint interval is supported **only** by discordant pairs and lies within about one insert size of a clip- or split-supported breakpoint, merge it into that breakpoint rather than keeping a separate block.
- Check before and after on the 60-event demo and the large pilot.

### 2. The clip refinement loop is quadratic (low-medium, performance)

- `_stamp_clip_positions_from_softclips` checks every clip for every block. Measured: 1,000 blocks × 10,000 clips 0.4 s; 2,000 × 20,000 1.4 s.
- A 30x chr20 with ~10k blocks and ~300k clipped reads extrapolates to roughly 100 s, growing with the square of chromosome size.
- **Fix:** sort clip positions once and use `bisect` per interval, O((blocks + clips) log clips).
