# Parity with the original ARC-SV

Target (§10.2): on the same BAM and region, at least 99% of original calls reproduced with the same rearrangement and genotype, and a relative score difference below 1e-6.

This tree has not been run against `example/expected_output.tab` yet. The example BAM and a working `pysam` install of commit `dd6f795` (with `np.Inf` changed to `np.inf`) are required. `tests/oracle/setup_oracle.sh` builds that environment; `tests/oracle/run_oracle.py` writes the oracle table.

## Known differences to investigate before claiming parity

1. **Insert KDE.** ARC-SV2 convolves a Gaussian kernel with the integer histogram. The original calls `sklearn.neighbors.KernelDensity` with `rtol=1e-6`. The bandwidth formula is the same. A parity run should feed both the same insert list and compare pmfs to 1e-12.
2. **Path neighbor order.** Paths are deterministic because adjacency neighbors are sorted by node id. igraph's neighbor order follows edge insertion, so the set of paths should match while the order of enumeration can differ.
3. **Hanging reads and insertions.** An unmapped mate is stored on the within-block edge and, with no novel insertion, contributes `class_probs[1]`. A mate on another chromosome or farther than 2 Mb is distant and contributes `class_probs[3]`. The hanging length is the mate's query length when that SAM line is present. Paths that contain an insertion add the overlap term from `orig:compute_hanging_edge_likelihood` at the first placement of the anchored node (`pr[0]`). A boundary with clips on both sides, or an insertion discordant pair, is tested at the log-spaced sizes and the winning block is appended. Split-read adjacency checks on the hanging end are still not applied. Soft clips and same-chromosome splits from the SAM path become breakpoints, and a split adds support on the within-read adjacency.
4. **Normalizer.** Gap and insertion corrections follow `orig:compute_normalizing_constant`. Contiguous half-open pieces join, which is what the original gap-overlap truth table requires. A 100 bp gap lowers the constant; a 60 bp insertion that restores the length matches the contiguous haplotype; a 62 bp insertion does not. Those cases are in `tests/test_normalizer.py`.
5. **Affected length.** Every co-optimal traceback is kept, in both string directions, and the affected block ids are the union. The original unions every optimal traceback of one direction and does not swap the strings.
6. **Copy number and within-block reads.** A placement is kept only when each end's block path is a contiguous subpath of the haplotype (`is_adj_satisfied`). A split is that path on the pair with its mate; the split edge itself is not scored again. Lower copy number, then homozygosity, is applied only inside a 0.5-nat band and only when the paths collapse to the same block sequence. Deletions and inversions keep the higher likelihood. `score_vs_next` is the margin to the best genotype outside the band. Short homozygous duplications can still be called heterozygous when the heterozygous likelihood leads by more than 0.5 nats. Flank within-block reads stay in `n`. The live original includes them by passing every locus block as `which_dup`; `duplicated_blocks` is unused. Split support walks that path, so `sr` counts a junction split even when one half starts a few bases into the previous block.
7. **Breakpoint uncertainty.** `bp_uncertainty` and `sv_bp_uncertainty` are the uncovered half-open gaps (`next.start - this.end`). The original sv column writes `hi - lo - 2` on the closed interval.
8. **Merge-filter and breakends.** Repeat, segdup, blacklist, and gap intervals are applied per chromosome. Allele count uses one dose per sample. VCF breakend brackets follow `orig:bnd_alt_string`: a forward left block is `N[mate[` or `N]mate]`, and a '-' orientation keeps the 0-based coordinate.
9. **Locus merge.** Expanded loci merge only when one starts strictly inside the previous one. Loci that share a cut-point block stay separate, matching `pyinter.open`.
10. **Novel skip edges.** `CallConfig.skip_edge_ref_gate` (default **off**) optionally withholds pair support on a skip `|i−k| > 1` when the insert under the reference path through the middle blocks is still inside `[q_low, q_high]`. Literal `add_pair` has no such test. Default is off (pure `add_pair`): original `-v 2` on HG01884 weak DELs 23857951 / 13358681 / 63458085 credits skip PE (support 27 / 23 / 25) and opens DEL paths, but genotype prefers reference HOM (`score_vs_ref` equivalent ≤ 0), so no call. ARC-SV2 already drops `score_vs_ref ≤ 0`; with gate off, local `call_evidence` also emits 0 near those sites. The gate remains available as an ARC-SV2-only veto if needed. See `docs/EDGE_SUPPORT.md`.
11. **Same-block tandem orientation.** A single-block `B.out↔B.in` between-mate edge gets pair support only when the reverse read is upstream of the forward read and the no-duplication insert is below `q_low`. Literal `add_pair` checks only the insert. Without the outward test, concordant pairs on a block about one insert long open pair-only tandem duplications (chr20:59.4–64.4 Mb: 13 such calls, 2 with the test restored). Multi-block mates use orig `flip_parity` between junction (often the tandem edge while the stored PE is a skip) with `alt_dist < q_low` only — no outward guard. Default block creation passes half-open CI intervals (gapped; Methods). `CallConfig.use_point_block_cuts` (default off) is an ablation toggle for contiguous point cuts (`breakpoint_block_cuts`); v2fix9 point cuts caused the INS/complex regression.

Discordant clustering only compares pairs whose reference starts fall inside `max_distance`. Path search uses an adjacency index. SAM records are paired as the file is read, and `--region chr:start-end` keeps pairs that overlap that window. BAM and CRAM use the same pairing through `pysam`; a CRAM requires the reference FASTA, and the fetch is limited to the index window. `max_mes_extra` defaults to 0, so a locus over 1,000 paths is skipped; a positive value raises edge support by 2 and retries. `--jobs` runs chromosome calls in separate processes. `--threads` greater than 1 builds one edge index for the chromosome and genotypes each locus from the edges of its blocks. Graph construction is still serial. A chromosome-scale timing still needs the example BAM; this tree does not record one. An insertion is written `>N` when no discordant pair has ends on both sides; a concordant pair across the reference breakpoint does not count. The call table appends `blocks` and `blocks_point`. `ml-label` builds sequences from `blocks_point` with 150 bp of each outer block, aligns them to haplotype FASTAs on either strand, and labels a heterozygote 1 when the reference allele is on the other haplotype. `ml-dataset` drops NA labels. A call table with a `label` column fits one scaled logistic model per class. PCA is fit on that class, folds are grouped by sample when the column is present, and a chromosome hold-out is stored with the threshold. Without that table, training still writes the paper presets and prediction reports `ml_model=untrained` with `ml_prob=NA`. `xgboost` is not installed here. The Rust kernels are still not called from Python. Model comparison waits for real labels.

Unit tests cover the deletion, duplication, and inversion affected-length cases from `orig:sv_affected_len.py::test_affected_len`, the complex-type table, and a constructed homozygous deletion.
